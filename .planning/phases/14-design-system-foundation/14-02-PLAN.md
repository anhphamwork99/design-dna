# Plan 14-02: Tailwind Theme Swap & Visual Validation

## Goal

Ensure the token swap from Plan 14-01 produces a clean, visually correct light-mode UI. Hunt and fix any hardcoded dark-mode colors that bypass the token system. Validate app builds and renders correctly.

## Context

- After Plan 14-01, app should render in light mode automatically because `@theme` values changed
- BUT: there may be hardcoded colors in JSX (`bg-[#111827]`, `text-white`, `border-gray-700`, etc.) that bypass tokens
- These hardcoded values were fine in dark mode but will look broken on light backgrounds
- Need to audit ALL components for hardcoded dark-mode colors and fix them

## Tasks

<task id="1">
Audit all source files for hardcoded dark-mode colors that bypass the token system.

Search for:
```bash
# Hardcoded dark hex colors in className or style props
grep -rn "#0B0F19\|#111827\|#1E293B\|#273549\|#374151\|#1F2937" app/src/ --include="*.tsx" --include="*.ts"

# Tailwind dark color classes (gray-700, gray-800, gray-900, slate-*, etc.)
grep -rn "bg-gray-\|bg-slate-\|border-gray-\|border-slate-\|text-gray-\|text-slate-" app/src/ --include="*.tsx" --include="*.ts"

# Hardcoded rgba(255,255,255,...) — white overlays designed for dark bg
grep -rn "rgba(255, 255, 255" app/src/ --include="*.tsx" --include="*.ts"

# Direct text-white on non-accent backgrounds
grep -rn "text-white" app/src/ --include="*.tsx" --include="*.ts"

# Inline style objects with color/background
grep -rn "backgroundColor:\|color:" app/src/ --include="*.tsx" --include="*.ts"
```

Create a list of all findings.
</task>

<task id="2">
Fix hardcoded colors — replace with token-based equivalents.

**Mapping:**
| Hardcoded (dark) | Replace with | Reason |
|-----------------|-------------|---------|
| `bg-[#0B0F19]` | `bg-bg-base` | Use token |
| `bg-[#111827]` | `bg-bg-surface1` | Use token |
| `bg-[#1E293B]` | `bg-bg-surface2` | Use token |
| `bg-gray-800/900` | `bg-bg-surface1/surface2` | Use token |
| `border-gray-700` | `border-border-default` | Use token |
| `text-white` on non-accent bg | `text-text-primary` | Light mode: dark text |
| `text-gray-400` | `text-text-tertiary` | Use token |
| `text-gray-300` | `text-text-secondary` | Use token |
| `rgba(255,255,255,0.x)` overlays | `rgba(0,0,0,0.x)` | Light mode: dark overlays |

**Keep `text-white` when:**
- Inside accent-colored buttons (`bg-accent text-white`)
- On dark overlay/modal backdrops
- On gradient/AI-purple backgrounds

**Do NOT change:**
- Token-based classes (e.g., `bg-bg-base`, `text-text-primary`) — already correct
- Colors used semantically (success, warning, error)
</task>

<task id="3">
Update `app/src/index.html`:

- Add `<link rel="preconnect" href="https://fonts.googleapis.com">` and `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` in `<head>` (performance)
- Update `<meta name="theme-color" content="#FAFAFA">` (was likely dark)
- Ensure `<meta name="viewport" content="width=device-width, initial-scale=1.0">` exists
