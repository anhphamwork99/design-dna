# Plan 14-01: Design Tokens & CSS Architecture

## Goal

Create the CSS foundation for the light-mode redesign: design tokens, reset, globals, utilities — organized in `styles/` folder. Restructure `index.css` as import-only entry point.

## Context

- Current `index.css` = 109 lines, single file, dark mode tokens via `@theme`
- Token names already semantic (`bg-base`, `text-primary`, etc.) — keep names, swap values
- Krea AI design system extracted in `.planning/research/DESIGN-SYSTEM.md` Section 12
- Font: Inter (already imported in current index.css!)
- No dark mode toggle — light only
- App uses Tailwind CSS v4 with `@theme` directive
