# Plan 11-02: Auto-Save Analysis + Frontend API Integration

## Objective
After a design analysis completes successfully, auto-save the result to Supabase via the backend. Add analysis CRUD functions to the frontend API client.

## Tasks

<task name="add-analyses-api-functions">
Add to `app/src/apiClient.ts`:

```typescript
// Analyses CRUD — calls /api/analyses (NOT /api/ai/)
export async function saveAnalysis(token: string, data: {
  name: string;
  thumbnail: string;
  resultJson: any;
}) { ... }

export async function listAnalyses(token: string, limit?: number, offset?: number) { ... }

export async function getAnalysis(token: string, id: string) { ... }

export async function deleteAnalysis(token: string, id: string) { ... }
```

**Note:** These call `/api/analyses` (not `/api/ai/`), so update `authFetch` or create a separate helper that doesn't prepend `/ai`.
</task>

<task name="auto-save-after-analysis">
Update `app/src/App.tsx` — `handleAnalyze` flow:

After `analyzeDesign()` returns successfully:
1. Generate thumbnail: resize the uploaded image to ~200px width using canvas
2. Call `saveAnalysis(token, { name: fileName, thumbnail, resultJson: result })`
3. Store the `savedAnalysisId` in state so the result screen knows it's saved
4. On save error: log warning but don't block — user still sees their result

The auto-save should be fire-and-forget (don't block the UI transition to results screen).
</task>

<task name="generate-thumbnail-helper">
Create a `generateThumbnail(dataUrl: string, maxWidth: number): Promise<string>` helper:

- Uses Canvas API (browser-only) to resize image
- Output as JPEG with quality 0.7 for small size
- Target: ~200px width, maintain aspect ratio
- Can live in `app/src/api.ts` (where `resizeImageIfNeeded` already lives) or a new utils file
</task>
