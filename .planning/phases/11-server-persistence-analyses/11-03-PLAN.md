# Plan 11-03: My Analyses UI — Landing Card + List + View

## Objective
Add "My Analyses" card to Landing screen, create analysis list page, enable viewing a saved analysis in DNA Card read mode, and enable deleting analyses.

```typescript

```

Add state:
```typescript
const [viewingAnalysisId, setViewingAnalysisId] = useState<string | null>(null);
```
</task>

<task name="add-landing-card">

<task name="create-analyses-list-component">
Create `app/src/components/MyAnalysesList.tsx`:

A list page showing saved analyses:

```tsx
interface Props {
  onNavigate: (s: Screen) => void;
  onViewAnalysis: (id: string) => void;
}
```

**Layout:**
- Back button → Landing
- Title: "My Analyses"
- Grid or list of analysis cards
- Each card shows: thumbnail, name, date (formatted), and summary snippet
- Click card → `onViewAnalysis(id)` 
- Delete button (with confirm dialog) on each card
- Empty state: "No analyses yet. Analyze a design to get started."
- Loading state: skeleton cards

**Data fetching:**
- On mount: call `listAnalyses(token)`
- Store in local state
- After delete: remove from local list (optimistic)

**Design:** Match existing dark mode aesthetic (bg-bg-surface1, border-border-default, rounded-xl, etc.)
</task>

<task name="view-analysis-screen">
Update `app/src/App.tsx`:

When `currentScreen === 'view_analysis'`:
1. Fetch full analysis: `getAnalysis(token, viewingAnalysisId!)`
2. Show loading spinner while fetching
3. Once loaded: render existing `ResultsScreen` component in READ mode
   - Pass `analysisResult` prop with the loaded `result_json`
   - Disable/hide "Create New" or "Go to Studio" actions that don't make sense in read mode
   - Add back button → My Analyses list
4. On error: show error message with retry option

**Important:** The existing `ResultsScreen` already knows how to render DNA Card data. Reuse it — just pass the loaded data instead of fresh analysis data. Add a `readMode` prop if needed to hide action buttons.
</task>

</task>
