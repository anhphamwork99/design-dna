  <action>
  Create `app/src/components/layout/` directory with 4 files:

  **SidebarNavItem.tsx:**
  - Props: `icon: React.ReactNode`, `label: string`, `to: string`, `active: boolean`, `collapsed: boolean`, `onClick?: () => void`
  - Use `<NavLink>` from react-router-dom for navigation
  - Active state: `bg-bg-surface2` background + `font-semibold` + dark gray 4px left border (use `border-l-4 border-text-secondary`)
  - Inactive state: `text-text-secondary hover:bg-bg-surface2 hover:text-text-primary` transition
  - When collapsed: icon only, centered. When expanded: icon + label with `gap-3`
  - Label should fade with `transition-opacity` (opacity-0 when collapsed)
  - Render as flex row, items-center, h-10, rounded-lg, px-3

  **Sidebar.tsx:**
  - State: `collapsed` boolean (default: `false` — expanded)
  - Layout: flex column, full height (`h-screen`), fixed left, bg-bg-primary (white), border-r border-border-default
  - Width: `w-60` (240px) when expanded, `w-16` (64px) when collapsed
  - Transition: `transition-all duration-300 ease-in-out` on width
  - Structure from top to bottom:
    1. **Logo area:** "DesignDNA" in `font-logo` (Dancing Script), `text-xl font-semibold`. Chevron toggle button (`«`/`»`) at right. Use `ChevronLeft` / `ChevronRight` from lucide-react.
    2. **WORKSPACE section:** Muted uppercase label (`text-[11px] font-medium text-text-tertiary uppercase tracking-wider px-3 mb-1`), then:
       - Home icon: `Home` from lucide → route `/`
       - Library icon: `Library` from lucide → route `/library`
    3. **TOOLS section:** Same label style, then:
       - Studio icon: `Palette` from lucide → route `/studio`
       - Analyze icon: `Microscope` from lucide → route `/analyze`
       - Compare icon: `Scale` from lucide → route `/compare`
    4. **Spacer** (`flex-grow`)
    5. **FOOTER section:** No section label, thin top border (`border-t border-border-default pt-2`):
       - Settings icon: `Settings` from lucide → route `/settings`
       - Sign Out: `LogOut` from lucide → onClick calls `signOut()` from AuthContext
  - Section dividers: `border-t border-border-default` between WORKSPACE and TOOLS sections
  - When collapsed: hide section labels, hide "DesignDNA" text (show only DNA icon or first letter), center toggle button
  - Pass `signOut` as prop (avoid importing AuthContext directly in Sidebar)

  **AppShell.tsx:**
  - Props: `children: React.ReactNode`
  - Layout: flex row, min-h-screen
  - Renders `<Sidebar>` + content area div
  - Content area: `flex-1`, `overflow-auto`, with padding `p-8`
  - Content area gets `margin-left` matching sidebar width — handled via flex layout (no manual margin needed since sidebar is in document flow)
  - Pass `signOut` from `useAuth()` to Sidebar

  ```typescript

  export { SidebarNavItem } from './SidebarNavItem';
  ```

  - Do NOT use `useNavigate()` in Sidebar — use `<NavLink>` via SidebarNavItem
  - Sign out is the ONLY non-route action in sidebar — handle via onClick prop
  - All icons from lucide-react (already installed)
  - Tailwind classes only — no custom CSS needed
