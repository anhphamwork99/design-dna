**PROMPT 1: BATCH COMPARE UI (Mock)**

This prompt adds the Batch Compare flow. Send as follow-up in AI Studio:

1. **Enable the "Compare Designs" button** on the Landing screen. Remove "DISABLED" state/badge. On click, navigate to a new screen: `currentScreen === "compare_upload"`.

2. **Compare Upload Screen (`currentScreen === "compare_upload"`):**
   - Header: "Compare Winning Designs" (H1) + "Upload 2-5 successful designs to uncover their shared DNA and extract the winning formula."
   - Back button: "← Home" (ghost)
   - **Upload Area:**
     - A container showing added images as a horizontal scrollable row or grid. Each image has a small "X" button to remove it.
     - An "Add Image" dashed area box (like the single upload, but smaller).
     - Text: "2/5 images selected" (Require at least 2 images to proceed).
   - **Action Button:** "Extract Winning Formula ✨" (AI gradient). Disabled if < 2 images.
   - On click: change screen to "compare_analyzing" (use the same skeleton/shimmer loader but with different text: "Analyzing patterns across designs..."), wait 3 seconds, then go to `currentScreen === "compare_results"`.

3. **Compare Results Screen (`currentScreen === "compare_results"`):**
   - Header: "Winning Formula" + ghost back button ("← New Comparison")
   - Layout: Split view. Left side (30% width, sticky) shows thumbnails of the uploaded images in a vertical stack or 2-col grid. Right side (70% width) shows analysis content.
   
   - **Content Sections (Right Side):**
   - **Section 1: The Winning Formula (Top Highlight)**
     - Large card (surface2 bg, 2px accent border).
     - Title: "The Winning Formula" (18px, bold, accent color).
     - Content mock: "Kawaii illustration + pastel palette + handwritten font. Combined with breed-specific references, first-person voice, and daily-life humor."
     - Suggested Brief: "Create a kawaii-style illustration of a Golden Retriever in a work-from-home setting, with first-person humorous text about pet-parent life. Pastel palette, handwritten font."
     - Button: "Generate from Formula" (AI gradient bg). On click, navigate to `currentScreen === "generation"` and pre-fill the generation prompt/SHIFT+B values using this brief.
   
   - **Section 2: Buyer Overlap Map**
     - Section title: "Buyer Overlap" (16px, semi-bold). 
     - Mock content:
       - Shared Persona: "Women 25-35, pet owners, work-from-home"
       - Shared Identity: "Defines self through pet relationship"
       - Shared Emotion: "Warmth + gentle humor about pet parenting"
       - Shared Occasion: "Everyday casual wear, gifts between pet-parent friends"
   
   - **Section 3: "Made For Me" Patterns**
     - Section title: "Pattern Analysis" (16px, semi-bold).
     - Mock content (list of pill badges or checklist items):
       - "All top sellers use BREED-SPECIFIC references (not generic 'dog')"
       - "4/5 use FIRST-PERSON voice ('I'd rather be with my dog')"
       - "3/5 use cute/kawaii illustration style"
       - "0/5 use realistic photo style — all illustrated"
     - Specificity Ladder visualization (3 rows):
       - Generic: "I love dogs ❌ (too broad)"
       - Niche: "I love golden retrievers ✅"
       - Hyper-niche: "My golden retriever is my coworker ✅✅ (highest conversion)"

4. **Responsive Strategy:**
   - Desktop: Left 30%, Right 70%.
   - Mobile: Images appear as a single horizontal scrolling row at the top. Content stacks below.

**PROMPT 2: WIRE BATCH COMPARE API**

Follow-up to connect real Gemini API for comparison:

1. **Call Gemini API for Comparison:**
   When "Extract Winning Formula" is clicked, construct a request to `gemini-2.5-pro`.
   - Send ALL the uploaded images in the `contents` array (Gemini accepts multiple inlineData parts).
   - Prompt: "Act as a merchandising analyst. Analyze these successful designs as a batch to find their shared visual and buyer psychological patterns. Output ONLY a JSON object with this structure: { batch_analysis: { buyer_overlap: { shared_buyer_profile: { persona, shared_identity, shared_emotion, shared_occasion }, made_for_me_patterns: [ array of strings ], buyer_insight, specificity_ladder: { generic, niche, hyper_niche } }, winning_formula: { visual, buyer, suggested_brief } } }"
   
2. **Handle Response:**
   - Parse the JSON response.
   - Update the mock data in the "compare_results" screen with the parsed data.
   - If error, use the same error handling components from F1/F2 (show error card, retry).

3. **Wire "Generate from Formula" Button:**
   - When clicked, navigate to the `generation` screen.
   - Set Generation Mode to "Full Remix" (so all toggles are Change).
   - Pre-fill the Text inputs in SHIFT+B based on the extracted `suggested_brief` or `winning_formula.visual` / `winning_formula.buyer`.
   - E.g., S: Extract subject from brief, H: Extract palette from brief, etc., OR just dump the `suggested_brief` into an overriding prompt string.
   - (*Tip: Tell Gemini Build Mode to pass the `suggested_brief` into the Generation view's state.*)

**PROMPT 3: FIX TEMPLATES**

- **Fix File Upload UX:** "The multiple image uploader is clunky. Ensure it uses a single `<input type='file' multiple accept='image/*'>` hidden behind the 'Add Images' dropzone. When images are added, append them to the existing array up to maximum 5. Display a tiny 'X' button in the top-right corner of each thumbnail over a dark semi-transparent circle to remove it."
- **Fix Specificity Ladder UI:** "The Specificity Ladder should look like steps. Use a left border line spanning the 3 items to connect them. For 'Generic', use a muted text color. For 'Hyper-niche', use the accent color and make it slightly bolder. Add the check/cross emojis next to them exactly as passed in data."
- **Fix Formula Routing:** "The 'Generate from Formula' button is not passing data correctly. Ensure it calls `setCurrentScreen('generation')` and passes an object like `{ source: 'batch_compare', brief: data.winning_formula.suggested_brief }`. On the generation screen, if `source === 'batch_compare'`, pre-fill the constructed generation prompt with this brief instead of relying strictly on the DNA card's original values."
