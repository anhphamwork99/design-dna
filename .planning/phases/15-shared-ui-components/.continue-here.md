## Hotfixes (sau phase completion)
1. **CSS architecture revert:** Ban đầu tách index.css thành 4 files (reset, globals, utilities, tokens) → gây vỡ layout vì:
   - `reset.css` conflict với Tailwind v4 preflight
   - `--radius-*` tokens trong `@theme` override Tailwind defaults (`rounded-sm/md/lg/xl`)
   - CSS cascade ordering bị sai khi import từ separate files
   - **Fix:** Revert về single-file index.css (giống original structure), chỉ thay color values
   - Files `styles/reset.css`, `globals.css`, `utilities.css`, `tokens.css` vẫn tồn tại nhưng KHÔNG được import

2. **CORS fix:** `access-control-allow-origin` header thiếu trên error responses (401)
   - Root cause: Hono CORS cần origin function (trả về string) thay vì static string
   - **Fix:** Changed to `origin: (origin) => origin` pattern + explicit allowHeaders

3. **Header icon buttons:** Thêm `p-2 rounded-lg hover:bg-bg-surface2` cho Settings/SignOut buttons

<decisions_made>

- **Single-file CSS:** Tailwind v4 + Hono works best with `@theme` inline in same file as `@import "tailwindcss"`. Separate files caused cascade issues.
- **No custom radius tokens:** Dùng Tailwind defaults cho `rounded-*`. Custom radius override gây vỡ toàn bộ layout.
- **Shared components chưa apply:** Phase 15 chỉ CREATE components, Phase 16+ mới INTEGRATE vào screens. User đã hiểu.
- **CORS function pattern:** Hono `cors()` cần `origin: (origin) => origin` thay vì static string để set header trên error responses.
</decisions_made>
