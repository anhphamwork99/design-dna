# Plan 20-01: State Machine + Types + Goal Picker Stage

## Objective

Replace the boolean-soup state management (17 useState calls) with a clean Stage enum, define all new types, implement the Goal Picker stage, and handle the "entry from Analyze" scenario. This plan lays the state foundation that Plans 02 and 03 build upon.

## Context

Current `CreativeStudio.tsx` (1,063 LOC) uses ~17 boolean/value useState calls to track flow state: `isSynthesizing`, `isGenerating`, `showResult`, `showPatternPanel`, `showSectionDialog`, etc. The CONTEXT.md specifies replacing this with a `Stage` enum that makes impossible states impossible.

The redesign replaces the creativity slider (1-5) with 3 goal cards: Clone, Variations, Explore. Goals map to pipeline behavior but the pipeline functions (`synthesizeConcept`, `generateArtwork`, `cloneDesign`) stay unchanged.

### Rewrite StudioScreen.tsx as the new state-machine shell

Rewrite `app/src/screens/StudioScreen.tsx` to become the main orchestrator:

- Import `Stage`, `StudioGoal`, types from `studio/types.ts`
- Import `GoalPicker` from `studio/GoalPicker.tsx`
- State management with Stage enum:
  ```typescript
  const [stage, setStage] = useState<Stage>('goals');
  const [goal, setGoal] = useState<StudioGoal | null>(null);
  const [uploadedImage, setUploadedImage] = useState<{data: string; name: string; type: string} | null>(null);
  const [analysisResult, setAnalysisResult] = useState<any>(null);
  ```
- Handle "entry from Analyze" via `useLocation().state`:
  ```typescript
  const location = useLocation();
  useEffect(() => {
    const state = location.state as { analysisResult?: any; uploadedImage?: any } | null;
    if (state?.analysisResult && state?.uploadedImage) {
      setAnalysisResult(state.analysisResult);
      setUploadedImage(state.uploadedImage);
      // Skip upload — show goal picker with preloaded image
    }
  }, [location.state]);
  ```
- Render based on `stage`:
  - `'goals'` → `<GoalPicker />`
  - Other stages → placeholder `<div>Stage: {stage} (coming in Plan 02/03)</div>`
- `handleSelectGoal`:
  - Set `goal` state
  - If image+DNA already loaded → `setStage('studio')` (skip upload)
  - Else → `setStage('upload')`
- `handleStartOver`:
  - Keep `uploadedImage` and `analysisResult`
  - Reset `goal`, concepts, artwork
  - `setStage('goals')`
- No topbar needed — sidebar handles navigation (Phase 16/17 decision)
- Remove the `onNavigate` prop from old `CreativeStudio` — sidebar is primary navigation
</task>
