# Plan 20-02: Upload + Analysis + Clone Flow

## Objective

Implement the Upload → Auto-Analyze → Clone flow stages. After this plan, users can enter Studio → pick "Clone Design" → upload image → auto-analyze → see clone preview → generate clone → view side-by-side result. This completes the Clone path end-to-end.

## Context

Plan 20-01 creates the Stage enum and GoalPicker. This plan implements stages: `upload`, `analyzing`, `cloning`, and `clone-result`. It also implements the `studio` stage specifically for Clone mode (preview + aspect ratio + CTA).

The clone flow is simpler than variations/explore — it skips synthesis entirely and calls `cloneDesign()` directly. This makes it a good first implementation to validate the stage machine works.

<task id="1">
### Create UploadStage component

Create `app/src/studio/UploadStage.tsx`:

- Uses the existing shared `UploadZone` component from `components/shared/`
- Goal-aware description text:
  - Clone: "Upload the product photo you want to extract"
  - Variations: "Upload the design you want to riff on"
  - Explore: "Upload the design for inspiration"
- Shows selected goal name in a small breadcrumb/tag at top
- On file drop/select:
  1. Read file as data URL
  2. Resize using `resizeImageIfNeeded` from `api.ts`
  3. Call `onImageReady(imageData)` callback
- Props:
  ```typescript
  interface UploadStageProps {
    goal: StudioGoal;
    onImageReady: (image: { data: string; name: string; type: string }) => void;
    onBack: () => void;  // Return to goal picker
  }
  ```
- Layout: centered on full canvas area, max-width ~500px
- Include "← Back to goals" link at top-left
- Supported formats display: PNG, JPG, WEBP
</task>

<task id="3">
### Create CloneStudio component

Create `app/src/studio/CloneStudio.tsx`:

Handles both the clone **preview** and **result** stages:

**Preview stage (`stage === 'studio'` with `goal === 'clone'`):**
- Left area: Original image displayed large on canvas
- Right sidebar (overlaid or inline): Aspect ratio picker + "Clone This Design" CTA button
- User sees what they're about to clone before committing

**Cloning stage (`stage === 'cloning'`):**
- Canvas shows loading animation: "Extracting & recreating design..."
- Reuse loading pattern from AnalyzingStage but with different text

**Clone result stage (`stage === 'clone-result'`):**
- Side-by-side layout: Original (left) | Clone (right)
- Both images same size, rounded borders
- Label above each: "Original" | "Clone"
- Action buttons below clone: Download, Re-clone, Start Over

- Logic handlers (called from StudioScreen):
  ```typescript
  interface CloneStudioProps {
    stage: 'studio' | 'cloning' | 'clone-result';
    uploadedImage: { data: string; name: string; type: string };
    analysisResult: any;
    clonedImage: string | null;
    error: string | null;
    aspectRatio: string;
    onAspectRatioChange: (ratio: string) => void;
    onClone: () => void;
    onReClone: () => void;
    onDownload: () => void;
    onStartOver: () => void;
  }
  ```
- Aspect ratio options: 1:1, 4:5, 3:4, 4:3, 16:9, 9:16 (same as current)
</task>

### Wire stages into StudioScreen.tsx

Update `StudioScreen.tsx` to integrate the new stage components:

- Add `stage` transitions for upload/analyzing/clone flow:
  ```typescript
  // After goal selected as 'clone':
  // If image+DNA preloaded → stage='studio'
  // Else → stage='upload'
  
  // After image uploaded:
  handleImageReady → start analyzeDesign() API call → stage='analyzing'
  
  // After analysis complete:
  → stage='studio' (clone preview with sidebar)
  
  // After "Clone This Design" clicked:
  handleClone → start cloneDesign() API call → stage='cloning'
  
  // After clone complete:
  → stage='clone-result' (side-by-side)
  ```

- Import and call `cloneDesign()` from `apiClient.ts` for clone generation
- Handle errors: `stage` stays at current, error banner shown inline
- Error from analyze → centered error on canvas with "Try Again" + "Upload Different Image"
- Error from clone → stay on clone preview with error banner + retry

- The `stage` transitions:
  ```
  goals → upload → analyzing → studio (clone preview) → cloning → clone-result

  ```
