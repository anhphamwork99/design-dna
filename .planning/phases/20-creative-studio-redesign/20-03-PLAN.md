# Plan 20-03: Variation/Explore Studio + Concept Cards + Cleanup

## Objective

Implement the Variation/Explore flow: sidebar configuration → synthesize concepts → horizontal concept strip → fullscreen concept dialog → generate artwork → artwork on cards → final actions. Then remove the old `CreativeStudio.tsx` and wire up the "Go to Studio" action from AnalyzeScreen.

## Context

Plans 20-01 and 20-02 established the Stage enum, GoalPicker, Upload, Analyzing, and Clone flow. This plan completes the Studio by implementing the more complex Variation/Explore path, which involves:
1. Left sidebar with shifts + pattern picker + aspect ratio
2. Concept synthesis (3 cards)
3. Concept detail dialog (fullscreen)
4. Artwork generation onto cards
5. Result actions (download, regenerate, start over)

This is the most complex plan because it replicates the core creative pipeline UX.

### Create VariationStudio component

Create `app/src/studio/VariationStudio.tsx`:

The main studio layout for Variations and Explore goals.

**Layout: Sidebar (left, ~260px) + Canvas (center, flex-1)**

**Left sidebar sections:**

1. **Original Image** — Small thumbnail (80x80) + filename + DNA tags (style, harmony, tribe, emotion)

2. **Dimension Shifts** — 7 dimensions with Keep/Change/Reimagine toggle per dimension:
   - Each dim: name label + segmented control (Keep | Change | Reimagine)
   - When "Change" selected: text input appears for optional direction
   - For "Explore" goal: default all to "Reimagine" (from `getDefaultShifts`)
   - For "Variations" goal: default Style+Colors to "Change", rest "Keep"
   - **LOCKED DECISION:** 3-state toggle (Keep/Change/Reimagine) replaces the old binary Keep/Change. The `Shifts` type's `keep` boolean maps as: keep=true → "Keep", keep=false+value="" → "Reimagine", keep=false+value!="" → "Change with direction"

3. **Pattern Picker** — Expandable section:
   - "Add Pattern" button → loads patterns via `listPatterns()` API
   - Pattern list: clickable items with thumbnails + name
   - On select → Section Selection Dialog (reuse from old code)
   - Applied pattern shown as chip with X remove

4. **Aspect Ratio** — Select dropdown (same options as Clone)

5. **"Create Concepts" CTA** — Primary button at bottom of sidebar

**Props:**
```typescript
interface VariationStudioProps {
  goal: 'variations' | 'explore';
  stage: Stage;
  uploadedImage: { data: string; name: string; type: string };
  analysisResult: any;
  
  // Shift state
  shifts: Shifts;
  onShiftsChange: (shifts: Shifts) => void;
  
  // Pattern state
  appliedPattern: AppliedPatternData | null;
  onApplyPattern: (pattern: AppliedPatternData) => void;
  onRemovePattern: () => void;
  
  // Aspect ratio
  aspectRatio: string;
  onAspectRatioChange: (ratio: string) => void;
  
  // Concepts
  concepts: SynthesizedConcept[];
  conceptArtworks: Map<number, string>;  // index → artwork data URL
  
  // Actions
  onCreateConcepts: () => void;
  onGenerateArtwork: (conceptIndex: number) => void;
  onRegenerateArtwork: (conceptIndex: number) => void;
  onDownload: (imageDataUrl: string, title: string) => void;
  onStartOver: () => void;
  
  // Loading states
  error: string | null;
}
```

**Handler functions (port logic from old CreativeStudio.tsx):**
- `handleCreateConcepts()` → calls `synthesizeConcept()` → sets concepts → `stage='concepts'`
- `handleGenerateArtwork(index)` → calls `generateArtwork()` → updates conceptArtworks map → `stage='result'`
- `handleRegenerateArtwork(index)` → clears artwork for that card → re-generates
- `handleDownload(imageDataUrl, title)` → create download link
- `handleStartOver()` → reset to 'goals', keep image+DNA

**Stage rendering additions:**
- `stage === 'studio'` + `goal !== 'clone'` → `<VariationStudio />`
- `stage === 'synthesizing'` → loading indicator in VariationStudio canvas area
- `stage === 'concepts'` → concept strip visible in VariationStudio
- `stage === 'generating'` → concept detail dialog with loading
- `stage === 'result'` → artwork rendered on cards in VariationStudio

**Note on goal switching:**
When selecting goal in GoalPicker, also set shifts to `getDefaultShifts(goal)` so Variations and Explore start with different defaults.

**CRITICAL:** Remove the `analyzeBuyerFit()` call — per CONTEXT.md, buyer fit is REMOVED from Studio entirely. The old right panel (Buyer Fit) is eliminated.
