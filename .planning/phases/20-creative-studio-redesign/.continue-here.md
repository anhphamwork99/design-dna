<decisions_made>

### Flow
- Goal picker (3 large cards) shown FIRST, then upload zone (separate step)
- From Analyze screen → "Go to Studio" → Goal picker (skip upload, image+DNA available)
- No goal switching mid-flow — must "Start Over" to return to Goal picker
- "Start Over" keeps image+DNA, resets concepts/artwork

### Upload & Analysis
- Upload zone: goal-aware description text + supported formats
- Auto-analyze on drop (no button)
- Loading: full-canvas animation, image shrinks to corner, step text progression
- Analyze complete → auto-transition to Studio (no confirmation)
- Error: inline center canvas + "Try Again" + "Upload Different Image"

### Studio Canvas
- Concept cards: horizontal scroll strip, 3 compact cards
- Click card → fullscreen dialog (near full-screen, backdrop blur, ESC/X close)
- Generate → dialog closes, artwork renders directly ON the concept card
- Hover card → quick action icons overlay; Click card → dialog with full artwork + all actions

### Clone vs Variation/Explore
- Clone: preview original image + sidebar (aspect ratio only) + CTA → side-by-side result (original left, clone right)
- Variation/Explore sidebar: shifts (top) + pattern picker (mid) + aspect ratio (bottom) + "Create Concepts" CTA
- Default shifts: Variations = 2 CHANGE + 5 KEEP; Explore = all REIMAGINE

### Removed
- Buyer fit (`analyzeBuyerFit()`) — REMOVED from Studio entirely

### State Management
- Stage enum replaces 17 boolean useState calls
