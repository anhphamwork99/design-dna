# Plan 10-03: Frontend API Client Refactor

## Objective
Replace the current `api.ts` (881 lines, Gemini SDK + prompts) with a thin `apiClient.ts` that calls the Hono backend proxy instead. Remove `@google/genai` dependency from frontend.

## Tasks

<task name="create-api-client">
Create `app/src/apiClient.ts`:

Thin HTTP client that calls backend proxy routes:

```typescript
const API_BASE = import.meta.env.VITE_API_URL || 'http://localhost:4000';

async function authFetch(path: string, body: any, token: string) {
  const res = await fetch(`${API_BASE}/api/ai${path}`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`,
    },
    body: JSON.stringify(body),
  });

  if (!res.ok) {
    const err = await res.json().catch(() => ({ code: 'UNKNOWN', message: 'Request failed' }));
    throw new Error(err.message || `HTTP ${res.status}`);
  }

  return res.json();
}
```

Export functions matching current api.ts signatures (but calls backend):
- `analyzeDesign(token, imageData, mimeType)` → `POST /api/ai/analyze`
- `analyzeBatch(token, images)` → `POST /api/ai/compare`
- `synthesizeConcept(token, input)` → `POST /api/ai/synthesize`
- `generateArtwork(token, input)` → `POST /api/ai/generate`
- `cloneDesign(token, input)` → `POST /api/ai/clone`
- `analyzeBuyerFit(token, prompt)` → `POST /api/ai/buyer-fit`

**Key changes from current api.ts:**
- First param is `token` (Supabase session token) instead of `apiKey`
- No Gemini SDK import — just HTTP fetch
- No prompt strings — just sends data payloads
- Image resize (`resizeImageIfNeeded`) STAYS in frontend (uses Canvas API)
- Types (`SynthesizedConcept`, `SynthesizeInput`, etc.) stay in a shared types file or in apiClient

**Progress callbacks:** For `generateArtwork` and `cloneDesign`, the frontend currently uses `onProgress` callback. Since these are now HTTP calls (not streaming), switch to a simple polling approach or show indeterminate progress. The backend handles the full pipeline and returns the final result.
</task>
