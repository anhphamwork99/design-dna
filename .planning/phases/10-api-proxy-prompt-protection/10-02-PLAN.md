# Plan 10-02: Backend Proxy Routes — Move Prompts Server-Side

## Objective
Move ALL Gemini prompts from `app/src/api.ts` to `api/src/prompts/` and create proxy routes on the Hono backend. After this plan, zero prompt strings exist in frontend code.

## Tasks

<task name="create-prompts-helpers">
Create `api/src/prompts/helpers.ts`:

Move these helper functions from `app/src/api.ts` to server-side:
- `cleanJsonResponse()` — strips markdown code fences from Gemini responses  
- `CREATIVITY_FIDELITY` object — fidelity gradient instructions per creativity level
- `CREATIVITY_IMAGE_ROLES` object — image reference role per creativity level
- `DIMENSION_LABELS` object — with `richContext` and `shortLabel` functions
- `packageFullDna()` — formats full DNA as text for Gemini
- `formatPatternInsights()` — formats pattern data for synthesis prompt

These are **pure business logic** — no DOM dependencies, move as-is.
</task>

<task name="create-ai-routes">
Create `api/src/routes/ai.ts`:

Proxy routes that use auth middleware + prompts:

```typescript
import { Hono } from 'hono';
import { authMiddleware } from '../middleware/auth.js';
import { getGeminiClient } from '../lib/gemini.js';

const ai = new Hono();
ai.use('*', authMiddleware);

// POST /api/ai/analyze — single design analysis
// POST /api/ai/compare — batch comparison (2-5 images)
// POST /api/ai/synthesize — concept generation
// POST /api/ai/generate — artwork generation (two-pass)
// POST /api/ai/clone — design cloning (subtle mode)
// POST /api/ai/buyer-fit — buyer fit scoring
```

Each route:
1. Extract user from context
2. Get Gemini client (loads encrypted key from DB, decrypts)
3. Parse request body (images as base64, dimensions, settings)
4. Call appropriate prompt function
5. Return result as JSON
6. On error: return consistent `{ code, message }` format (PROXY-04)

**Timeout handling (PROXY-05):**
- Generation routes (`/generate`, `/clone`) may take 60-120s
- Do NOT set aggressive timeouts on these routes
- Use Hono's built-in timeout middleware with 120s for AI routes
- Frontend already has its own timeout handling
</task>

<task name="register-routes">
Update `api/src/index.ts`:

```typescript
import { aiRoute } from './routes/ai.js';
app.route('/api', aiRoute);
```

Also apply rate-limit middleware to AI routes:
```typescript
import { rateLimiter } from './middleware/rateLimit.js';
ai.use('*', rateLimiter);
```
</task>
