# Plan 10-01: Backend API Key Management + Gemini SDK Setup

## Objective
Set up backend infrastructure: Supabase client for API, encryption utilities for API keys, auth middleware to verify Supabase JWT, and CRUD routes for API key management. Also install Gemini SDK on backend.

<task name="create-crypto-utils">
Create `api/src/lib/crypto.ts`:

Simple encryption/decryption for API keys using Node.js built-in `crypto`:

```typescript
import { createCipheriv, createDecipheriv, randomBytes, scryptSync } from 'crypto';

const ENCRYPTION_KEY = process.env.ENCRYPTION_KEY!; // 32-byte hex string
const ALGORITHM = 'aes-256-gcm';

export function encrypt(text: string): string {
  const iv = randomBytes(16);
  const key = scryptSync(ENCRYPTION_KEY, 'salt', 32);
  const cipher = createCipheriv(ALGORITHM, key, iv);
  let encrypted = cipher.update(text, 'utf8', 'hex');
  encrypted += cipher.final('hex');
  const authTag = cipher.getAuthTag().toString('hex');
  return `${iv.toString('hex')}:${authTag}:${encrypted}`;
}

export function decrypt(encryptedText: string): string {
  const [ivHex, authTagHex, encrypted] = encryptedText.split(':');
  const iv = Buffer.from(ivHex, 'hex');
  const authTag = Buffer.from(authTagHex, 'hex');
  const key = scryptSync(ENCRYPTION_KEY, 'salt', 32);
  const decipher = createDecipheriv(ALGORITHM, key, iv);
  decipher.setAuthTag(authTag);
  let decrypted = decipher.update(encrypted, 'hex', 'utf8');
  decrypted += decipher.final('utf8');
  return decrypted;
}
```
</task>

<task name="create-auth-middleware">
Create `api/src/middleware/auth.ts`:

Middleware to verify Supabase JWT from Authorization header and attach user to context:

```typescript
import { createMiddleware } from 'hono/factory';
import { createClient } from '@supabase/supabase-js';

export const authMiddleware = createMiddleware(async (c, next) => {
  const authHeader = c.req.header('Authorization');
  if (!authHeader?.startsWith('Bearer ')) {
    return c.json({ code: 'UNAUTHORIZED', message: 'Missing or invalid token' }, 401);
  }

  const token = authHeader.replace('Bearer ', '');

  // Create a per-request Supabase client with the user's JWT
  const supabase = createClient(
    process.env.SUPABASE_URL!,
    process.env.SUPABASE_ANON_KEY!,
    { global: { headers: { Authorization: `Bearer ${token}` } } }
  );

  const { data: { user }, error } = await supabase.auth.getUser(token);
  if (error || !user) {
    return c.json({ code: 'UNAUTHORIZED', message: 'Invalid or expired token' }, 401);
  }

  c.set('user', user);
  c.set('supabase', supabase);  // User-scoped client for RLS
  await next();
});
```
</task>

<task name="create-api-key-routes">
Create `api/src/routes/api-keys.ts`:

CRUD endpoints for API key management:

- `GET /api/api-keys` — check if user has a saved key (returns `{ hasKey: boolean }`, NEVER returns the actual key)
- `POST /api/api-keys` — save or update API key (encrypt before storing)
- `DELETE /api/api-keys` — remove saved API key

Each endpoint:
1. Gets user from auth middleware context
2. Queries/mutates `api_keys` table via user-scoped Supabase client
3. Returns consistent error JSON: `{ code: string, message: string }`
</task>

<task name="create-gemini-helper">
Create `api/src/lib/gemini.ts`:

Helper to get a Gemini AI instance for a user:

```typescript
import { GoogleGenAI } from '@google/genai';
import { decrypt } from './crypto.js';

export async function getGeminiClient(supabase: any, userId: string): Promise<GoogleGenAI> {
  const { data, error } = await supabase
    .from('api_keys')
    .select('encrypted_key')
    .eq('user_id', userId)
    .eq('provider', 'gemini')
    .single();

  if (error || !data) {
    throw { code: 'NO_API_KEY', message: 'No Gemini API key configured. Add one in Settings.' };
  }

  const apiKey = decrypt(data.encrypted_key);
  return new GoogleGenAI({ apiKey });
}
```
</task>
