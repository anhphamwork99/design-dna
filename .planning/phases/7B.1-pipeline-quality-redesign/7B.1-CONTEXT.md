# Phase 7B.1 Context — Pipeline Quality Redesign

## Why This Phase Exists

Real user testing (2026-03-16) revealed:
1. Generated designs too similar despite creativity slider
2. Background inconsistency with PNG inputs
3. Concepts lack text content (quotes, slogans)

First-principles audit identified root causes:
- DNA utilization gap: only 8/30+ fields used in synthesis (25%)
- Creativity level controls DNA exposure instead of fidelity
- Keep × High creativity creates conflicting directives
- Schema missing text content, color palette, made-for-me hook

## Design Spec

See: `DESIGN.md` in this directory — full pipeline redesign with:
- 3 Axioms (DNA = ground truth, Creativity = fidelity dial, POD = Visual + Text + Buyer)
- Fidelity gradient model (resolves Keep×Creativity conflicts)
- Expanded SynthesizedConcept schema (+3 new fields)
- Rich generation prompt (text content + hex palette)

## Decisions Already Made

| Decision | Choice |
|----------|--------|
| Send full DNA to synthesis? | Yes — always 100%, creativity controls fidelity not exposure |
| Add text content to concepts? | Yes — `suggestedText: { primary, secondary, textStyle }` |
| Add color palette to concepts? | Yes — `colorPalette: [{ hex, name, role }]` |
| Resolve Keep×Creativity conflict? | Fidelity gradient — KEEP means "feel connected" not "copy exactly" |
| REIMAGINE includes original? | Yes — "REIMAGINE Colors (original: Earthy warm)" |
| Change UI layout? | No — only concept card content changes |
