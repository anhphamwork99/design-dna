# Plan 7B.1-02: Concept Card UI Enrichment

## Objective
Update CreativeStudio concept card to display the 3 new fields from the expanded SynthesizedConcept schema.

## Reference
- Plan 7B.1-01 defines the new schema fields
- No structural UI changes — same 3-panel layout, same carousel

## Tasks

### Task 1: Update concept card to show suggestedText

In the concept carousel card (AnimatePresence section), add a "Suggested Text" section:

```tsx
{/* Suggested Text */}
{concept.suggestedText && (
  <div>
    <span className="text-[11px] font-medium text-text-tertiary uppercase tracking-wider">
      Design Text
    </span>
    <p className="text-[14px] text-accent font-semibold mt-1">
      "{concept.suggestedText.primary}"
    </p>
    {concept.suggestedText.secondary && (
      <p className="text-[12px] text-text-secondary mt-0.5 italic">
        "{concept.suggestedText.secondary}"
      </p>
    )}
    <span className="inline-block mt-1.5 bg-bg-surface2 px-2 py-0.5 rounded text-[10px] text-text-tertiary">
      {concept.suggestedText.textStyle}
    </span>
  </div>
)}
```

Position it AFTER description, BEFORE the existing Visual Direction section.

### Task 2: Add color palette swatches

After the Visual Direction section, add color palette display:

```tsx
{/* Color Palette */}
{concept.colorPalette && concept.colorPalette.length > 0 && (
  <div>
    <span className="text-[11px] font-medium text-text-tertiary uppercase tracking-wider">
      Color Palette
    </span>
    <div className="flex items-center gap-2 mt-1.5">
      {concept.colorPalette.map((color, i) => (
        <div key={i} className="flex items-center gap-1.5" title={`${color.name} (${color.role})`}>
          <div
            className="w-5 h-5 rounded-full border border-border-default flex-shrink-0"
            style={{ backgroundColor: color.hex }}
          />
          <span className="text-[11px] text-text-secondary">{color.name}</span>
        </div>
      ))}
    </div>
  </div>
)}
```

### Task 3: Add madeForMeHook display

After Target Buyer section, add the hook:

```tsx
{/* Made For Me Hook */}
{concept.madeForMeHook && (
  <div>
    <span className="text-[11px] font-medium text-text-tertiary uppercase tracking-wider">
      "Made For Me" Hook
    </span>
    <p className="text-[13px] text-text-primary mt-1 bg-accent/5 border border-accent/10 rounded-lg px-3 py-2">
      💡 {concept.madeForMeHook}
    </p>
  </div>
)}
```

### Task 4: Update SynthesizedConcept import

Ensure the import from `./api` includes the updated type (no code change needed if using the same type name, but verify the import is correct).
