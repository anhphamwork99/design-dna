# Plan 12-02: Frontend API Client & Storage Deprecation

## Objective
Update the frontend API client to interact with the new `/api/patterns` backend routes. Deprecate the existing localStorage-based `patternStorage.ts` for reading and writing new patterns, but preserve its read functions slightly modified for the Phase 13 migration.

## Tasks

<task name="export-pattern-type">
In `app/src/patternStorage.ts` (or preferably move the type to `app/src/apiClient.ts` if better, but maybe just rename/keep the type as `SavedPattern` in `apiClient.ts`):
- Migrate `SavedPattern` type to `apiClient.ts`.
- Rename `patternStorage.ts` functions to `legacyGetPatterns`, `legacyGetPattern`, `legacyDeletePattern`.
- Remove `savePattern` entirely from `patternStorage.ts` (since we only need to read old patterns for migration).
- Add `// DEPRECATED: For Phase 13 migration only` comments above the legacy functions.
</task>

<task name="frontend-pattern-api">
In `app/src/apiClient.ts`:

Add new `SavedPattern` type to match the new backend format:
```typescript
{
  id: string;
  name: string;
  summary: string;
  source_image_count: number;
  thumbnails: string[];
  batch_analysis: any;
  created_at: string;
}
```

Add these API client functions:
- `listPatterns(token)` → GET `/api/patterns`
- `getPattern(token, id)` → GET `/api/patterns/:id`
- `savePattern(token, data)` → POST `/api/patterns` (passing `name`, `summary`, `sourceImageCount`, `thumbnails`, `batchAnalysis`)
- `deletePattern(token, id)` → DELETE `/api/patterns/:id`
- `checkPatternSaved(token, summary: string)` → helper to fetch list of patterns and check if any matches the summary (replaces `isCompareResultSaved`).

**Note on Check Saved:** `checkPatternSaved` can just GET `/api/patterns` and manually find if any `summary` matches the parameter. Since the summary is already returned in `listPatterns`, this isn't too heavy.
</task>

<task name="thumbnail-helper">
Ensure `resizeToThumbnail` is accessible if it was originally in `patternStorage.ts`. Move it to `api.ts` or `apiClient.ts` so `CompareScreens.tsx` can use it before calling `savePattern`.
</task>
