# Plan 12-03: Replace Local Storage with Patterns API

## Objective
Update all UI components that previously imported and used `patternStorage.ts` to now fetch/save from the `apiClient.ts` asynchronously with proper loading states.

## Tasks

<task name="refactor-compare-screens">
Update `app/src/CompareScreens.tsx` (`CompareResultsScreen` component):
- Fetch the auth token using `useAuth()`.
- Use the new `checkPatternSaved(token, summary)` instead of `isCompareResultSaved`. Since this is async, make it run in a `useEffect` on mount.
- In `handleSavePattern`: 
  - Call the `resizeToThumbnail` helper (now moved to `apiClient.ts` or `api.ts`) for each source image if needed, or if the API layer does it, just pass the raw data. Wait, the API client could handle resizing, or it could happen before the API call. Let's do it right before `savePattern`.
  - Pass the token and the pattern data payload.
  - Make `isSaving` a state and display a spinner while writing to DB.
</task>

<task name="refactor-pattern-library">
Update `app/src/PatternLibrary.tsx`:
- Add `useAuth()` to get the token.
- Introduce `isLoading` state (default true).
- Use `useEffect` to call `listPatterns(token)`:
  - Then update the `patterns` state.
  - Set `isLoading(false)`.
- Use a loading spinner or skeleton while `isLoading` is true.
- In `handleDelete`:
  - Await `deletePattern(token, id)`, then re-fetch `listPatterns(token)` (or optimismally remove the item from local state list).
- Change field references: `pattern.createdAt` to `pattern.created_at`, `pattern.sourceImageCount` to `pattern.source_image_count` (depending on exact shape returned from API).
</task>

<task name="refactor-pattern-detail">
Update `app/src/PatternDetail.tsx`:
- Get the token from `useAuth()`.
- Since it only takes a `patternId` prop, add `isLoading` state.
- Use `useEffect` to fetch `getPattern(token, patternId)`.
- Replace `pattern.createdAt` with `pattern.created_at` where appropriate.
- Render after fetching.
- Also handle `deletePattern` just like the library using async `deletePattern(token, id)`.
</task>

<task name="refactor-creative-studio">
Update `app/src/CreativeStudio.tsx`:
- Find where `getPatterns()` is called (likely for the "Pattern Picker" drawer to apply a pattern instead of a fresh generation).
- Create a `useEffect` that fetches `listPatterns(token)` when the drawer opens or on component mount.
- Update property usages mappings.
</task>

<task name="refactor-app-tsx">
Fix import errors in `app/src/App.tsx` from renaming `getPatterns` or removing it, if it was used anywhere directly. Ensure the component renders `PatternLibrary` and `PatternDetail` without type errors.
</task>
