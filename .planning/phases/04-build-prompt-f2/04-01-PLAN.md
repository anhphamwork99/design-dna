**PROMPT 2: WIRE GENERATION API**

Follow-up to connect real Gemini image generation:

1. **Build the generation prompt from SHIFT+B state:**
   Construct a text prompt from the current controls:
   - Start with mode context (same buyer/new buyer/full remix)
   - For each SHIFT+B dimension set to "Change": include the user's text
   - For each set to "Keep": reference original DNA values
   - Append creativity level instruction (map level to prompt specificity)
   - Append specificity level
   - Append source DNA summary

2. **Call Gemini image generation:**
   ```
   POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash-exp:generateContent?key={API_KEY}
   ```
   Request body includes the constructed prompt asking Gemini to generate an image.
   Parse response for generated image (base64 in response).

3. **Call Buyer Fit analysis:**
   After image is generated, automatically call gemini-2.5-flash with:
   - The generated image
   - The original DNA data
   - Prompt: "Compare this generated design against the original buyer DNA. Score: buyer_match (0-100), emotion_match (0-100), originality (0-100), made_for_me_signal_count (0-5). Return JSON."
   Display scores in the Buyer Fit card.

4. **Chat refinement:**
   When user sends a refinement message:
   - Add message to chat history
   - Re-call image generation with: original prompt + chat history as additional context
   - Show loading state on send button
   - Replace image with new result
   - Re-run Buyer Fit analysis

5. **Download:**
   Convert generated image base64 to blob → create download link → trigger download as "designdna-generated-{timestamp}.png"

6. **Error handling:**
   Same pattern as Phase 3 Prompt 2 — network, API, timeout, parse errors with retry.
