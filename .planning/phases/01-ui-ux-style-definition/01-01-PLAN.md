Create `.planning/deliverables/STYLE-GUIDE.md` with the following sections. Use 01-CONTEXT.md decisions as LOCKED specifications and fill in Agent's Discretion areas with high-quality defaults inspired by Raycast's dark UI aesthetic.

**SECTION 1 — Design Philosophy**
- One-paragraph aesthetic summary: Raycast-inspired, dark mode, polished, "alive" feel
- Anti-patterns to avoid (glow effects, gradients on non-AI elements, overly playful/rounded)

**SECTION 2 — Color System**
Define complete palette with exact values:
- **Base:** `#0B0F19` (background)
- **Surfaces:** `#111827` (surface-1), `#1E293B` (surface-2), derive surface-3 for elevated elements
- **Borders:** `rgba(255,255,255,0.06)` default, `rgba(255,255,255,0.1)` for hover, `rgba(255,255,255,0.15)` for active
- **Brand accent:** `#0096ED` — define solid uses (buttons, links, active tabs, selected states)
- **AI Gradient:** `#0096ED → #7C3AED` (blue-to-purple) — define where to use (analyze/generate buttons, loading shimmer, AI-active states)
- **Text colors:** Primary (white ~`rgba(255,255,255,0.92)`), secondary (muted ~`rgba(255,255,255,0.6)`), tertiary (~`rgba(255,255,255,0.4)`)
- **Semantic colors:** Success green, Warning amber, Error red — with exact HEX
- **States:** Hover overlays, focus rings, disabled opacity

**SECTION 3 — Typography System**
- **Font stack:** Inter (primary) with Plus Jakarta Sans as alternative. Specify Google Fonts import.
- **Scale:** H1=32px/700, H2=20px/600, Body=14px/400, Small=12px/400, Caption=11px/400
- **Line heights:** Headings 1.2, Body 1.5, Small 1.4
- **Weight strategy:** Labels = 400 + muted color, Values = 500/600 + primary color
- **Letter spacing:** Headings -0.02em, Body 0, Small/Labels 0.02em uppercase
- Data display: Inline `Label: Value` — label in secondary color weight 400, value in primary color weight 500

**SECTION 4 — Spacing System**
- Base unit: 4px
- Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80
- Component internal padding: cards=24px, buttons=12px 20px, inputs=10px 14px
- Section gaps: 32px between major sections, 16px between items in a list
- Page margins: 32px desktop, 16px mobile

**SECTION 5 — Component Patterns**
Define visual specs for each component (NOT code, but specific enough for AI to generate):

5.1 **Cards (DNA Card, Action Card, Mini Card)**
- DNA Card: Split layout — image fixed left (40% width), scrollable content right (60%), surface-1 background, 1px border, border-radius=12px
- Action Cards (landing): surface-1 bg, hover→surface-2, 1px border, padding=24px, icon + title + description, border-radius=12px
- Mini Cards (Made For Me): surface-2 bg, padding=16px, icon left + title bold + explanation below, border-radius=8px, stacked with 8px gap, NO collapse/accordion

5.2 **Buttons**
- Primary: `#0096ED` bg, white text, border-radius=8px, 14px font, hover darken 10%
- AI Action: gradient `#0096ED→#7C3AED` bg, white text, subtle shimmer animation on hover
- Secondary: transparent bg, 1px border `rgba(255,255,255,0.1)`, white text, hover border brightens
- Ghost: transparent, text only, hover bg `rgba(255,255,255,0.06)`
- Disabled: 40% opacity, no pointer events

5.3 **Tabs**
- Underline style: text-only tabs, active = `#0096ED` underline + primary text, inactive = muted text, hover = slightly brighter text
- Tab bar bottom border: 1px `rgba(255,255,255,0.06)`

5.4 **Upload Zone**
- Dashed border `rgba(255,255,255,0.15)`, surface-1 bg, border-radius=12px
- Center-aligned: upload icon + "Drop image here or click to browse" + supported formats
- Hover: border brightens to `#0096ED`, subtle bg lightening
- Active/dragging: `#0096ED` border solid, bg tints with brand color 5% opacity

5.5 **Color Palette Display (DNA Card)**
- Proportional color bar: 5 horizontal segments, widths matching 60-30-10 ratio
- Height=40px, border-radius=8px (outer container), segments flush
- HEX codes below each segment, 11px caption text
- Harmony type + temperature labels below

5.6 **Sliders (Creativity Level)**
- Track: 4px height, surface-2 bg, border-radius full
- Fill: brand `#0096ED`
- Thumb: 16px circle, white fill, drop shadow, hover scale 1.1
- 5 discrete stops with labels below

5.7 **Inputs & Text Areas**
- surface-1 bg, 1px border `rgba(255,255,255,0.1)`, border-radius=8px
- Focus: border `#0096ED`, subtle ring `rgba(0,150,237,0.2)`
- Placeholder text in tertiary color

**SECTION 6 — Layout Patterns**

6.1 **App Shell**
- Topbar: 56px height, surface-1 bg, bottom border, logo icon + "DesignDNA" wordmark left-aligned
- Content: max-width 1200px, centered, page margins

6.2 **Landing Screen**
- Hero: centered, 1-2 line tagline H1 + subtitle in muted text
- Action cards: 3-column grid below hero, equal width, 16px gap

6.3 **Analysis Screen (DNA Card)**
- Split: image panel left (position: sticky, 40%), scrollable DNA content right (60%)
- Mobile: stack vertically, image on top

6.4 **Generation Screen**
- Single column, max-width 640px centered
- Sections stacked: mode → creativity → SHIFT+B → specificity → generate button

**SECTION 7 — Animation & Interaction**
- **Screen transitions:** fade + slight translateY (8px), duration 200ms, ease-out
- **Loading skeleton:** shimmer effect (gradient sweep left-to-right), surface-2 base, `rgba(255,255,255,0.05)` highlight
- **DNA Card results:** staggered fade-in, each section 100ms delay, 300ms duration — creates "AI thinking" effect
- **Button hover:** 150ms ease, darken or border-brighten
- **Tab switch:** content fade 150ms
- **Upload zone drag:** 200ms border/bg transition

**SECTION 8 — Responsive Breakpoints**
- Desktop: ≥1024px (split layouts, 3-col grids)
- Tablet: 768-1023px (stacked layouts, 2-col grids)
- Mobile: <768px (single column, full-width)

Format each section with clear headings, token tables (Token Name | Value | Usage), and visual hierarchy. This document should be directly paste-able into AI Studio System Instructions.
