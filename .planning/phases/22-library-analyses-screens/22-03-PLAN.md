    **Layout:**
    - Page header: `<h1>` "My Analyses" + subtitle "{N} analyses"
    - `<DataGrid>` with search, grid/list toggle

    **Grid card (renderGridItem):**
    - Card: `bg-bg-surface1 border border-border-default rounded-xl overflow-hidden cursor-pointer hover:border-border-hover transition-colors`
    - Top: Thumbnail (aspect-4/3, object-cover) — if no thumbnail, show `BookOpen` icon from lucide in a bg-bg-surface2 centered area

      - Row 1: Analysis name (h3, truncate, font-semibold) + ContextMenu [⋮] trigger
      - Row 2: Date — `formatDate(created_at)` in text-text-tertiary text-[12px]
      - Row 3: Visual DNA summary (line-clamp-2, text-[13px], text-text-secondary) from `result_json?.visual_dna?.summary`
    - Card onClick → navigate(`/library/analysis/${analysis.id}`)

    **List row (renderListItem):**
    - Horizontal: thumbnail (48x48 rounded-lg) + name + date + ContextMenu
    - Same hover/click behavior as grid card

    **Context menu items:**
    - View (Eye icon) → navigate(`/library/analysis/${id}`)

    - Icon: `BookOpen` (lucide)
    - Title: "No analyses yet"
    - Description: "Analyze a design to decode its Visual DNA and Buyer DNA."
    - CTA: "Analyze a Design" → navigate('/analyze')

    **formatDate helper:** Inline — `new Date(dateStr).toLocaleDateString(undefined, { year:'numeric', month:'short', day:'numeric' })`
