    Rewrite `LibraryScreen.tsx` as a self-contained screen (no delegation to PatternLibrary component).

    - `useState<SavedPattern[]>([])` for patterns, `loading` boolean, `error` string
    - `useEffect` on mount: call `listPatterns(session.access_token)`, populate state
    - Local state for `searchValue`, `viewMode` ('grid' | 'list'), `deletingId`

    **Search filtering:**
    - Filter patterns locally: `patterns.filter(p => p.name.toLowerCase().includes(searchValue.toLowerCase()))`
    - Pass filtered array to DataGrid

    **Layout:**
    - Page header: `<h1>` "Pattern Library" + subtitle showing count "{N} patterns"
    - `<DataGrid>` with search, grid/list toggle
    - `document.title = 'DesignDNA — Library'`

    **Grid card (renderGridItem):**
    - Card with `bg-bg-surface1 border border-border-default rounded-xl overflow-hidden cursor-pointer hover:border-border-hover transition-colors`
    - Top area: thumbnail mosaic — show first thumbnail as main image (aspect-4/3), or `Layers` icon placeholder if no thumbnails
    - Bottom area (p-4):
      - Row 1: Pattern name (h3, truncate, font-semibold) + ContextMenu [⋮] trigger (right-aligned)
      - Row 2: Meta — "{source_image_count} designs · {timeAgo(created_at)}" in text-text-tertiary text-[12px]
      - Row 3: Summary (line-clamp-2, text-[13px], text-text-secondary)
    - Card onClick → navigate to `/library/pattern/${pattern.id}`

    **List row (renderListItem):**
    - Horizontal row: small thumbnail (48x48, rounded-lg) + name + meta + ContextMenu [⋮]
    - `bg-bg-surface1 border border-border-default rounded-xl p-3 hover:border-border-hover cursor-pointer flex items-center gap-4`
    - onClick → navigate to `/library/pattern/${pattern.id}`

    **Context menu items:**
    - View (Eye icon) → navigate to `/library/pattern/${id}`
    - Use in Studio (Palette icon) → `navigate('/studio', { state: { patternId: id } })` (future hook)
    - Delete (Trash2 icon, variant: 'danger') → `window.confirm('Delete pattern "{name}"?')` → call `deletePatternById`, remove from local state

    **Empty state:**
    - Icon: `Layers` (lucide)
    - Title: "No patterns yet"
    - Description: "Compare multiple designs to discover shared patterns you can reuse."
    - CTA: "Go to Compare" → navigate('/compare')

    **timeAgo helper:** Inline (same logic as old PatternLibrary.tsx — just now, Nm, Nh, Nd, then date).
