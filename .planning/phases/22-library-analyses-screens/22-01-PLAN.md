  <action>
    **ContextMenu component** (`ContextMenu.tsx`):
    - Props: `items: { label: string; icon?: LucideIcon; onClick: () => void; variant?: 'default' | 'danger' }[]`, `trigger: React.ReactNode` (the [⋮] button), `align?: 'left' | 'right'`
    - Render a button (trigger) that toggles a dropdown menu positioned below/above the trigger
    - Use `useRef` + `useEffect` for click-outside detection to close
    - Close on Escape key
    - Close after any action item click (call onClick then close)
    - Dropdown styling: `bg-bg-surface1 border border-border-default rounded-[12px] shadow-xl p-1 min-w-[180px] z-50`
    - Each item: `px-3 py-2 rounded-[8px] text-[13px] flex items-center gap-2.5 hover:bg-state-hover transition-colors cursor-pointer`
    - Danger variant items: `text-error hover:bg-error/10`
    - Use `position: absolute` relative to trigger wrapper. Trigger wrapper is `position: relative; display: inline-flex`
    - Stop event propagation on trigger click (so parent card onClick doesn't fire)
    - No animations (user preference: no fade animations)
    - Use lucide icons if provided in items

    **DataGrid component** (`DataGrid.tsx`):
    - Generic component: `DataGrid<T>` with props:
      - `items: T[]` — data array
      - `loading: boolean` — show skeleton cards
      - `searchValue: string`, `onSearchChange: (value: string) => void` — controlled search
      - `viewMode: 'grid' | 'list'`, `onViewModeChange: (mode: 'grid' | 'list') => void` — controlled toggle
      - `renderGridItem: (item: T) => React.ReactNode` — render function for grid card
      - `renderListItem: (item: T) => React.ReactNode` — render function for list row
      - `emptyIcon: LucideIcon`, `emptyTitle: string`, `emptyDescription: string`, `emptyActionLabel?: string`, `emptyOnAction?: () => void` — empty state props
      - `searchPlaceholder?: string` — defaults to "Search..."
      - `skeletonCount?: number` — number of skeleton cards when loading (default: 6)
    - Header row: search input (left, with Search icon from lucide) + grid/list toggle buttons (right, using LayoutGrid + List icons from lucide)
    - Search input: `bg-bg-surface2 border border-border-default rounded-[10px] px-3 py-2 text-[13px] w-full max-w-[320px]` with Search icon inside
    - Toggle: two icon buttons, active one has `bg-bg-surface2 text-text-primary`, inactive has `text-text-tertiary hover:text-text-secondary`
    - Grid layout: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`
    - List layout: `flex flex-col gap-2`
    - Loading state: render `skeletonCount` skeleton cards — `bg-bg-surface1 border border-border-default rounded-xl overflow-hidden animate-pulse` with a `w-full aspect-[4/3] bg-bg-surface2` area and two bar placeholders below
    - Empty state: use `EmptyState` shared component with provided icon/title/description/action
    - If `items.length > 0` but search yields 0: show inline "No results for {query}" text (NOT the full EmptyState)
    - **Important:** DataGrid does NOT filter items itself — parent passes already-filtered items. DataGrid just controls layout and displays.

    **ImageLightbox component** (`ImageLightbox.tsx`):
    - Props: `open: boolean`, `onClose: () => void`, `src: string`, `alt?: string`
    - Fullscreen fixed overlay: `fixed inset-0 z-50 bg-black/80 backdrop-blur-sm flex items-center justify-center`
    - Image: `max-w-[90vw] max-h-[85vh] object-contain rounded-lg`
    - Top-right controls row: Download button + Close (X) button
    - Download: `<a>` tag with `href={src} download` attribute, lucide `Download` icon
    - Close: lucide `X` icon, also close on backdrop click and Escape key
    - Buttons styling: `bg-white/10 hover:bg-white/20 text-white rounded-full p-2.5 transition-colors`
    - Use same scroll-lock pattern as Modal.tsx (body overflow hidden when open)
    - No animations (user preference)
