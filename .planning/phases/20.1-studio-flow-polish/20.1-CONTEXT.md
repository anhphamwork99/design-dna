# Phase 20.1: Studio Flow Polish - Context

**Gathered:** 2026-03-18
**Status:** Ready for planning

<domain>
## Phase Boundary

Polish IA, layout, visual, and interactions for the Studio flow (Variation/Explore + Clone). No new features — only improve how existing functionality looks and feels. Floating panel redesign for Variation/Explore; Clone keeps its own layout.

</domain>

<decisions>
## Implementation Decisions

### Sidebar → Floating Panel (Variation/Explore only)
- Convert docked sidebar (260px) to **floating panel** overlaying canvas at left
- Panel **always visible** by default, toggle button to hide/show
- **No drag** — fixed position, left side
- Visual: **solid card + shadow-xl** (`bg-white` + `rounded-2xl` + shadow), consistent with light theme
- Width: **keep 260px**
- Clone flow **keeps its existing side-by-side layout** — floating panel is only for Variation/Explore

### Panel Content — Accordion Sections
- Sections are **accordion/collapsible** with click-to-expand headers
- **Dimension Shifts expanded by default**, all others collapsed
- "Your Original" section: **thumbnail + DNA tags only** (no filename)
- Shift mode control: **dropdown per dimension** — `Visual Style [Keep ▾]` — compact, click to select Keep/Change/Reimagine. Text input appears below when "Change" selected

### Navigation — Top Bar
- **Separate top bar** on canvas: `[🏠 Home] Studio > Make Variations`
- Exit icon: **Home** (`Home` from lucide) — clear destination
- Breadcrumb: clickable "Studio" to go back to goal picker, goal label as current

### CTA Placement
- "Create Concepts" CTA **only on canvas center** — panel has no CTA button
- Panel is config-only: shifts, patterns, output size
- Removes duplicate CTA confusion

### Canvas — Empty State
- Keep current centered layout (title + subtitle + CTA)
- **Replace Sparkles icon with illustration** (agent generates appropriate illustration)

### Concept Cards — Responsive + Unified
- Cards use **responsive sizing** (`flex-1` with min-width ~240px) — scale to fill available canvas
- **Unified card layout** for both states: artwork area (image or gradient placeholder) + text info below
- **Hover-only actions** (download, regenerate, zoom) — desktop-first, mobile deferred per v3.0 decisions

### Loading States — Unified MascotLoader
- **MascotLoader GIF for ALL loading states** — Analyzing, Cloning, Synthesizing, Generating
- Synthesizing: **full canvas takeover**, floating panel hides during loading
- Generating artwork: **MascotLoader inside the card** (small, ~60-80px) + **wave gradient animation at bottom of card**
- Other cards remain interactive during generation — **per-card loading state** (replaces current global `isGenerating` stage)
- Parallel artwork generation enabled — user can trigger generate on multiple concept cards

### Transitions
- **Smooth transitions only within canvas studio** (panel show/hide, concepts appear, loading states)
- Outer screen transitions (goals → upload → analyzing → studio) keep current behavior

### Agent's Discretion
- Exact illustration for empty state
- Wave gradient animation implementation details
- Accordion animation easing/duration
- Panel toggle button icon and position
- Top bar height and typography
- Exact min-width for responsive concept cards

</decisions>

## Existing Code Insights

### Reusable Assets
- `MascotLoader.tsx`: GIF-based loader, `size` prop — extend to all loading states
- `AiSphere.tsx`: CSS-only orb animation (unused) — can be removed as cleanup
- `AnimatePresence` from motion/react — already used for stage transitions
- `goalCards` config in `types.ts` — data-driven card rendering pattern

### Established Patterns
- Stage-machine architecture: `Stage` enum in `types.ts` — 10 stages
- `StudioScreen.tsx` (422 LOC) renders by stage with `AnimatePresence mode="wait"`
- `VariationStudio.tsx` (366 LOC) handles sidebar + canvas layout
- `CloneStudio.tsx` (258 LOC) handles clone-specific layout — will be minimally touched
- `ConceptCard.tsx` (107 LOC) + `ConceptDetailDialog.tsx` (280 LOC) — concept display

### Integration Points
- `StudioScreen.tsx` state machine needs per-card generating state (currently global `stage === 'generating'`)
- `VariationStudio.tsx` layout changes from `flex` (sidebar + canvas) to canvas-only + floating panel
- CSS tokens from `styles/tokens.css` — `--shadow-xl`, `--color-bg-surface1`, etc.
