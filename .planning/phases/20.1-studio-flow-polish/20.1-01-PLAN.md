# Plan 20.1-01: Floating Panel + Sidebar Redesign

## Summary

Convert the docked sidebar in VariationStudio to a floating panel overlay. Redesign shift controls from cramped 3-button toggles to dropdown selectors. Add accordion behavior to panel sections.

## Context Decisions (LOCKED)

- Panel: floating overlay, left side, 260px, solid card + shadow-xl
- Toggle button to show/hide, no drag
- Accordion: Shifts open by default, others collapsed
- "Your Original": thumbnail + tags only (no filename)
- Shift mode: dropdown per dimension — `Visual Style [Keep ▾]`
- Clone flow UNTOUCHED

<task id="02" title="Create AccordionSection component" commit="feat(20.1): add AccordionSection for panel sections">
Create accordion behavior inside FloatingPanel. Can be inline in FloatingPanel or a small sub-component.

1. `AccordionSection` props:
   - `title: string`
   - `defaultOpen?: boolean`
   - `children: React.ReactNode`

2. Structure:
   ```
   <div className="accordion-section">
     <button onClick={toggle} className="accordion-header">
       <span className="text-[11px] font-medium text-text-tertiary uppercase tracking-wider">{title}</span>
       <ChevronDown className={`w-3.5 h-3.5 transition-transform ${isOpen ? 'rotate-180' : ''}`} />
     </button>
     <AnimatePresence>
       {isOpen && (
         <motion.div initial={{ height: 0 }} animate={{ height: 'auto' }} exit={{ height: 0 }}>
           {children}
         </motion.div>
       )}
     </AnimatePresence>
   </div>
   ```

3. No border/bg per section — parent panel provides container styling

**Verification:**
- Sections collapse/expand smoothly
- ChevronDown rotates on toggle
- Height animation (not display:none)
</task>
