# Plan 20.1-03: Loading States + Concept Cards + Transitions

## Summary

Unify loading states to use MascotLoader everywhere, make concept cards responsive with unified layout, and add canvas-level smooth transitions. Requires floating panel layout (Plan 01) and top bar (Plan 02) to be complete.

## Context Decisions (LOCKED)

- MascotLoader for ALL loading (synthesizing, generating)
- Synthesizing: full canvas takeover, panel hides
- Generating: MascotLoader inside card + wave gradient bottom, per-card state
- Cards: responsive flex-grow, unified layout (placeholder/artwork + text below)
- Transitions: smooth within canvas only, outer screens unchanged

## Tasks

<task id="01" title="Responsive concept cards with unified layout" commit="feat(20.1): responsive concept cards with unified layout">
Rewrite `app/src/studio/ConceptCard.tsx`:

1. Remove fixed width (280px) and height (200px)
2. New layout — unified for both states:
   ```tsx
   <motion.div className="concept-card flex flex-col rounded-xl border border-border-default overflow-hidden bg-white">
     {/* Top area — artwork or placeholder */}
     <div className="aspect-[4/3] relative bg-gradient-to-br from-gray-50 to-gray-100">
       {concept.artworkUrl ? (
         <img src={concept.artworkUrl} className="w-full h-full object-cover" />
       ) : isGenerating ? (
         /* generating state — handled in task 03 */
       ) : (
         /* Gradient placeholder with color dots from concept palette */
         <div className="w-full h-full flex items-center justify-center">
           <div className="flex gap-2">
             {concept.colorPalette?.slice(0, 5).map(color => (
               <div key={color} className="w-6 h-6 rounded-full" style={{ backgroundColor: color }} />
             ))}
           </div>
         </div>
       )}
       
       {/* Hover actions overlay (artwork cards only) */}
       {concept.artworkUrl && (
         <div className="absolute inset-0 bg-black/40 opacity-0 hover:opacity-100 transition-opacity flex items-center justify-center gap-3">
           <button>Download</button>
           <button>Regenerate</button>
           <button>Zoom</button>
         </div>
       )}
     </div>
     
     {/* Bottom area — always show title + description */}
     <div className="p-3">
       <h4 className="text-[13px] font-semibold text-text-primary truncate">{concept.title}</h4>
       <p className="text-[11px] text-text-secondary line-clamp-2 mt-0.5">{concept.description}</p>
       {!concept.artworkUrl && !isGenerating && (
         <button className="mt-2 text-[11px] text-accent">Generate Artwork →</button>
       )}
     </div>
   </motion.div>
   ```

3. Update card container in VariationStudio — responsive grid:
   ```tsx
   <div className="grid grid-cols-[repeat(auto-fill,minmax(240px,1fr))] gap-4 p-6">
     {concepts.map(c => <ConceptCard key={c.id} ... />)}
   </div>
   ```

**Verification:**
- Cards fill available width (no fixed 280px)
- Both states (with/without artwork) have same structure
- Placeholder shows color palette dots
- Text always visible below image area
- Cards scale on different viewport widths
</task>
