## Objective

Implement one-time migration of existing localStorage patterns to Supabase on first login. When a user logs in and has patterns in localStorage (`designdna_patterns`), show a migration prompt with count, upload all patterns to Supabase via the existing `savePattern` API, then clear localStorage. Migration is idempotent — duplicate detection by `name + createdAt` prevents re-uploading.

## Tasks

<task id="1" title="Create useMigratePatterns hook">
**File:** `app/src/hooks/useMigratePatterns.ts` (new)

Create a custom React hook that handles the full migration lifecycle:

```typescript
interface MigrationState {
  status: 'idle' | 'detected' | 'migrating' | 'done' | 'error';
  localPatternCount: number;
  migratedCount: number;
  skippedCount: number;
  error: string | null;
}
```

**Detection logic (runs once on mount when session exists):**
1. Read `localStorage.getItem('designdna_patterns')` → parse JSON
2. If empty/null/no patterns → set status `idle`, return (silently skip)
3. If patterns found → set status `detected`, store `localPatternCount`

**Migration logic (called by `startMigration()`):**
1. Set status `migrating`
2. Fetch existing server patterns via `listPatterns(token)` for duplicate check
3. For each localStorage pattern:
   - Check duplicate: compare `name` + `createdAt` against server patterns' `name` + `created_at`
   - If duplicate → increment `skippedCount`, skip
   - If new → call `savePattern(token, { name, summary, sourceImageCount, thumbnails, batchAnalysis })` where fields map from `LegacySavedPattern` (camelCase) to `savePattern` args
   - Increment `migratedCount`
4. After all patterns processed: `localStorage.removeItem('designdna_patterns')`
5. Set status `done`

**Error handling:**
- If any `savePattern` call fails → log error, set status `error` with message
- Do NOT clear localStorage on error (user can retry)
- Partial migration OK — already migrated ones won't be re-uploaded (idempotent)

**Return:** `{ state: MigrationState, startMigration: () => Promise<void>, dismiss: () => void }`

`dismiss()` sets status back to `idle` (user declines migration).
</task>

<task id="2" title="Add migration banner UI in App.tsx">
**File:** `app/src/App.tsx`

Import and use `useMigratePatterns` hook inside the main `App` component, after auth gate (user is authenticated).

**Pass `session.access_token` to the hook.**

**Render a migration banner/modal when `state.status === 'detected'`:**
- Position: Top of app, below header — a styled banner (not a modal, less intrusive)
- Content: "📦 Found {localPatternCount} patterns in local storage. Migrate to your account?"
- Buttons: "Migrate Now" (calls `startMigration`) | "Not Now" (calls `dismiss`)
- Style: Match app's dark theme — subtle info banner with accent color

**When `state.status === 'migrating'`:**
- Show: "Migrating patterns... ({migratedCount}/{localPatternCount})"
- Disable buttons, show spinner

**When `state.status === 'done'`:**
- Show: "✓ {migratedCount} patterns migrated successfully{skippedCount > 0 ? `, ${skippedCount} already existed` : ''}"
- Auto-dismiss after 3 seconds

**When `state.status === 'error'`:**
- Show: "Migration failed: {error}. Your local patterns are safe — try again later."
- Button: "Retry" (calls `startMigration`) | "Dismiss" (calls `dismiss`)
</task>
