# POD Artwork Reference

## Desired Output Style

Artwork generation phải đạt chuẩn in ấn POD:

### ✅ MUST HAVE
- **White/transparent background** — KHÔNG gradient, texture, scene
- **Flat illustration style** — clean lines, cartoon/hand-drawn
- **Bold decorative typography** — mixed fonts, playful lettering
- **Character elements** — stylized people, pets, objects
- **Print-ready isolation** — artwork floats cleanly, dễ place lên garment

### ❌ MUST NOT HAVE
- 3D effects, shadows, lighting
- Glass morphism, surface textures
- Photorealistic rendering
- Background scenes, gradients, frames
- Reflections, bokeh, lens effects
