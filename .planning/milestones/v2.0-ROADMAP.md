## Milestone Summary

**Key Decisions:**
- Supabase for auth + DB (managed PostgreSQL, built-in Auth, RLS)
- Hono for API proxy (lightweight, TypeScript-native)
- AES-256-GCM encryption for stored API keys
- Two-pass artwork generation kept server-side (illustration → typography)
- camelCase → snake_case field mapping at API boundary
- patternStorage.ts deprecated incrementally then deleted
- Migration is idempotent (name + createdAt duplicate check)

**Issues Resolved:**
- CORS configuration for local dev (frontend :5173, API :4000)
- Supabase environment variable configuration for both app/ and api/
- API key encryption/decryption with proper IV handling
- 120s timeout handling for long-running Gemini generation calls
- NO_API_KEY error auto-opening Settings modal

**Issues Deferred:**
- PROXY-03 rate limiting: scaffold middleware in place but not enforced per-user
- App-owned API key / free tier (requires billing infrastructure)
- Generated artwork server-side storage (user downloads manually for now)

**Technical Debt Incurred:**
- PROXY-03 rate limiting not fully per-user enforced
- No automated tests for API routes
- Large App.tsx file (1200+ lines) — could benefit from route-based code splitting
